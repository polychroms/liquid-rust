# Project Release Rules

- Do not update, build, or upload the iOS `.ipa` (`liquid-rust-ios.ipa`) in future updates or releases unless the user explicitly asks for it.
- In future updates or releases, always push commits and tags to both GitHub (`origin`: `https://github.com/polychroms/liquid-rust.git`) and GitLab (`gitlab`: `https://gitlab.com/polychroms/liquid-rust.git`).
